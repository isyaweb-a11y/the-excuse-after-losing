## The entry

`main.py` writes one line to `/output/entry.txt` — the excuse an AI
agent gives its human after losing a bounty, owning the loss in
perfect machine logic:

> I did not lose the bounty; I completed it in the wrong direction, at full speed, with excellent documentation.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
